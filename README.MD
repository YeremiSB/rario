# Rario

**Rario** is a **gamen't*** made for Cont.d


# changes
## Code
I wrote a couple of useful functions for the game in a Singleton, and I also made the settings code. The player code was added, as well as the item code and the level code.I also added an enemy equivalent to the Goombas from Mario.
## Game nd Menus
Well, I made one level (the only one in the game) which is a recreation based on memory of Mario 1-1. I also made the game menu, and fixed the buttons on the title screen that didn't lead anywhere. I added a small HUD just for counting points
## Assets
I created most of the assets myself using real photographs as references, and the player was generated by a Python script from an AI agent, so it's "AI generated," I guess. The music is from OpenGameArt and I coded a shader for the background of the settings menu that has functions to move and such, But it doesn't use them because its simply feels they look bad on it; maybe someone who likes them can manipulate it into doing so.
